# REChain SDK's Parachain Template

> This is a template for creating a parachain based on the REChain SDK.
> It is synchronized alongside releases in the main REChain SDK monorepo.

A REChain SDK based project such as this one consists of:

- Substrate FRAME-based runtime
- Cumulus-based parachain integrations
- Templates and utilities to get started quickly

Download the `rechain` binaries from REChain SDK releases and expose them on `PATH`.

For a technical introduction, see https://docs.rechain.network

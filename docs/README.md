# REChain SDK Documentation

Welcome to the comprehensive documentation for the REChain SDK - the most advanced blockchain platform developed by REChain Network Solutions LLC.

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/REChain-Network-Solutions/SDK.git
cd SDK

# Build the project
cargo build --release --workspace

# Run tests
cargo test --workspace
```

### Running a Node

```bash
# Start development chain
cargo run --bin rechain -- --dev

# Connect to Polkadot.js Apps
# Visit: http://localhost:9944
```
